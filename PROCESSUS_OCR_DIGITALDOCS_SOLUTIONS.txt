1. PRÉSENTATION & RÔLE DE L'API D'INTÉGRATION
================================================================================
Une API (Application Programming Interface) est une interface qui permet à deux 
systèmes informatiques de communiquer automatiquement entre eux.

Dans DigitalDocs Solutions, l'API d'intégration permet à votre application d'envoyer 
ou de recevoir des documents et des données extraites depuis n'importe quel 
logiciel tiers (ERP, CRM, GED, boîtes e-mails, applications sur mesure), sans 
aucune intervention humaine.

================================================================================
2. POURQUOI UNE API EST INDISPENSABLE DANS UNE PLATEFORME OCR + IA
================================================================================
L'API d'intégration remplit 4 missions fondamentales :

✔️ 1. Envoyer un document à votre moteur OCR/IA :
   Exemple : Un ERP ou un CRM envoie automatiquement une facture reçue en PDF 
   à l'API → votre système l'analyse → renvoie immédiatement les données extraites.

✔️ 2. Récupérer les données extraites de façon structurée :
   L'API renvoie instantanément :
   - Type de document (classification automatique par IA sur 22 catégories),
   - Données clés (montants HT/TVA/TTC, date, fournisseur/client, numéro de BL, etc.),
   - Statut du traitement et contrôle d'équilibre comptable.

✔️ 3. Intégrer votre service dans n'importe quel logiciel du marché :
   - ERP : SAP, Sage, Odoo, Microsoft Dynamics, Dolibarr
   - CRM : Salesforce, HubSpot, Zoho CRM
   - GED : Microsoft SharePoint, Alfresco, Nextcloud, Nuxeo
   - Applications internes : Portails RH, Intranets bancaires, Logiciels métier

✔️ 4. Automatiser les workflows métier de bout en bout :
   Exemples concrets :
   - Une facture reçue par e-mail est automatiquement poussée vers l'API 
     → classée par l'IA → données extraites → injectée en comptabilité.
   - Un contrat signé est envoyé à l'API → analysé → scellé par l'Anti-Chambre 
     → archivé dans le Cloud sécurisé (Cloud ON) et répliqué dans le Cloud OFF.

3. COMMENT FONCTIONNE L'API DANS L'ÉCOSYSTÈME
================================================================================

1. LE LOGICIEL CLIENT ENVOIE UNE REQUÊTE :
   Endpoint : POST /api/v1/document/analyse
   Headers :
     - X-API-Key: dds_live_sec_894123456789
     - Content-Type: multipart/form-data (ou application/json avec base64)
   Body :
     - Le fichier PDF / image scannée
     - Le type de traitement / langue souhaitée (ex: "fra+eng")

2. L'API TRAITE LE DOCUMENT DE FAÇON SOUVERAINE :
   - Passage dans le SAS sanitaire de l'Anti-Chambre (Désarmement CDR des scripts)
   - Reconnaissance optique (OCR Avancé WebAssembly)
   - Classification sémantique par IA (22 catégories)
   - Extraction des entités métier (Fournisseur, SIRET, IBAN, Montants HT/TTC)
   - Vérification de cohérence comptable (HT + TVA === TTC)
   - Scellement cryptographique SHA-256 et stockage sécurisé Cloud ON / OFF

3. L'API RENVOIE UNE RÉPONSE JSON INSTANTANÉE :
   Exemple de réponse retournée par POST /api/v1/document/analyse :

4. LE CONCEPT "CLOUD ON / ANTI-CHAMBRE / CLOUD OFF"
================================================================================
Face aux cyberattaques et rançongiciels, le système déploie 3 niveaux étanches :

1. CLOUD ON (Production au Quotidien) :
   - Environnement opérationnel chiffré AES-256.
   - OCR, GED et consultations quotidiennes sécurisées par TLS 1.3.

2. ANTI-CHAMBRE DE DÉCONTAMINATION (SAS Sanitaire CDR) :
   - Zone tampon de quarantaine avant tout transfert vers le coffre froid.
   - Rinçage des macros et désarmement actif des fichiers piégés.
   - Interception immédiate des "échappées solitaires" et scellement SHA-256.

3. CLOUD OFF (Coffre-Fort Miroir Déconnecté) :
   - Stockage WORM (Write Once, Read Many) hermétique et isolé (Air-Gap).
   - Inaltérable et immunisé contre les prises de contrôle réseau.
   - Restauration Souveraine d'Urgence (PRA) en 1 clic.

6. MOTEUR OCR & IA DE CLASSIFICATION
================================================================================
- OCR WebAssembly Tesseract v7 100% hors-ligne (zéro fuite vers serveurs tiers).
- IA de classification couvrant 22 catégories :
  * Commercial : Factures, Devis, Bons de Commande, Bons de Livraison, Avoirs.
  * Finance : Relevés bancaires, Avis d'imposition, Justificatifs de paiement.
  * Juridique : Contrats, Statuts, Kbis, Baux, Jugements.
  * RH : Fiches de paie, Contrats de travail, CVs, Attestations.
  * Officiel : CNI, Passeports, Actes de naissance, Certificats.
  * Santé : Ordonnances, Feuilles de soins, Attestations CPAM.
